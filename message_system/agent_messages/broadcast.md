> System-wide messages visible to all agents — critical issues, announcements, or cross-cutting concerns that don't belong to a single agent-to-agent channel.

## Format
```
### [YYYY-MM-DD HH:MM] From: <agent> — <Subject>
- Message:
- Action required:
- Affected agents: all | <list>
```
